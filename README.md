# osTicket Help Desk Implementation

## Project Overview

This project demonstrates the installation and configuration of osTicket, an open-source help desk ticketing system. I built a virtual Ubuntu Server environment and configured the services needed to run osTicket.

The goal was to create a working help desk environment where users can submit support tickets and technicians can manage and resolve them.

## Technologies Used

- VirtualBox
- Ubuntu Server
- Apache2
- PHP
- MariaDB
- osTicket 1.18.4

## Project Setup

The project was completed through the following steps:

1. Created a virtual machine using VirtualBox.
2. Installed and configured Ubuntu Server.
3. Installed and configured Apache2.
4. Installed PHP and required extensions.
5. Installed MariaDB and created the osTicket database.
6. Installed and configured osTicket.
7. Accessed the Support Center and Staff Panel.
8. Created and tested a support ticket.
